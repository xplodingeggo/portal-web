# SDK reference — read only

`portal-sdk-2013/` is the Source SDK 2013 with the Portal code, kept here **for reference only**.

- Not part of the website's build or runtime; nothing imports from it.
- Git-ignored: never commit it.
- The website ports behavior from it by hand (portal placement, movement, `func_door`, scenes, ...). Look here to see how the original engine does a thing, then implement it in `src/`.
